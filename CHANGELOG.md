# Changelog

## 1.0.0

First release.

- Resolution, refresh rate, orientation, scaling and DPI on any monitor
- Twelve slots, each with its own hotkey
- Switch when a program opens, switch back when it closes
- Every change undoes itself after 15 seconds unless you keep it
- Reset a monitor back to normal in one click, or every monitor at once with
  Ctrl + Alt + Shift + R from anywhere
- Updates itself from GitHub
- Light and dark, tray, start with Windows
- Installer and portable zip, x64 and arm64
